产品介绍

电商做图，还在为存图发愁？

竞品分析、素材收集、店铺上新……电商详情页里藏着大量高质量商品图， 但原生页面并不提供批量保存能力。图提取就是为了解决这个问题而生。

图片高度分散

主图、SKU 图、详情长图散落在轮播、懒加载、背景样式和内联脚本里，右键另存要逐张翻找。

无法批量保存

平台页面不提供打包下载，一张张手动保存既耗时又容易漏图、存错图。

格式规格不一

webp、jpg 混用，尺寸参差不齐，拿到手还要逐个转格式、改名字才能入库使用。

核心功能

六个功能，覆盖存图全流程

从扫描页面到落盘保存，每一步都替你做好。

一键提取

自动扫描页面全部商品图，兼容懒加载属性与响应式 srcset，滚动过的图都不会漏。

智能过滤

自动排除图标、logo、占位图、1×1 像素图与小于 100×100 的无效图片。

集中预览

提取结果在新标签页网格化展示，缩略图、尺寸信息一目了然。

自由勾选

全选、反选、单张点选，只下载真正需要的图片，不多存一张废图。

统一 PNG

自动将 webp、jpg 等格式统一转为 PNG，入库即用，无需二次转码。

批量下载

一键保存到本地，文件名按 商品图_001.png 自动编号，进度与结果实时反馈。

安装步骤

四步完成安装

开发者模式本地加载，无需商店审核，即装即用。

  1. 1

    下载并解压

    从 GitHub 下载插件压缩包，解压到本地任意文件夹（建议路径不含中文）。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 后回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载扩展程序

    点击「加载已解压的扩展程序」，选择解压后的文件夹即可。
