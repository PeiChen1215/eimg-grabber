How It Works

三步上手

1

加载扩展

打开 Chrome chrome://extensions，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选择本项目文件夹。

2

打开商品详情页

进入淘宝 / 天猫 / 京东 / 拼多多商家版的任意商品详情页，页面右下角会出现紫色悬浮按钮「获取图片」。

3

勾选并下载

点击按钮自动提取并打开画廊页，勾选需要的图片，点击「下载选中」，稍等片刻即可在下载目录中获得 PNG 文件。

Architecture

技术架构

Manifest V3 · Content Script + Service Worker + 扩展页面三层协作

📁 项目结构
manifest.json        # MV3 配置与权限声明
content.js / .css    # 悬浮按钮 + 页面图片提取
background.js        # SW：消息路由 / 转码 / 存储
gallery.html/js/css  # 画廊预览与批量下载
icons/               # 扩展图标 (16-128px)
test/run-tests.js    # 52 项纯函数单元测试
  • Manifest V3：activeTab / scripting / downloads / storage 最小权限集，host_permissions 精确覆盖三大平台域名。
  • Content Script：纯函数式提取管线，SPA 路由轮询适配，平台差异化懒加载属性全兼容。
  • Service Worker：fetch + createImageBitmap + OffscreenCanvas 服务端转码，storage.session 跨页传参并自动过期清理。
  • 跨域三级兜底：页面 Canvas → SW fetch（host 权限加持）→ 原图直存，任一级成功即完成。
  • 可测试：提取逻辑全部为纯函数，Node 环境下 52 项断言全部通过。
